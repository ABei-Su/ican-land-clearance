## 实际存在的差异

1. **启动职责已取得，服务器细节仍未知**。用户提供的官方代码提交指南明确：上传整个 src 文件夹的压缩包及独立启动脚本；平台自动启动仿真和裁判，脚本只启动自己的包。示例脚本位于 scripts/。我方入口符合职责要求，现支持工作空间根目录或 scripts/，也支持 ICAN_WORKSPACE；仍会执行 colcon build。指南未明确服务器实际放置路径、预加载 overlay、编译是否计时及依赖安装方式。
2. **导航节点由我方启动，与指南保留 navigation 的示例一致**。我方将 Nav2 速度重映射到 /mission/nav_vel，由 land_velocity_gate 唯一发布 /cmd_vel。若平台另开导航、遥控或自动控制节点，会冲突或触发保护终止；不能移除保护来掩盖问题。
3. **本机运行措施**。平常训练采用 CycloneDDS、8 MB UDP 缓冲、临时暂停 Linux 校时，以及 90 秒准备等待；提交脚本不带这些设置，任务默认等待 40 秒。本次额外从干净环境演练默认入口，结果见后文。WSL 与官方 Linux 服务器的渲染、CPU、DDS 和启动速度仍有差异。
4. **导航策略不同于示例**。相对官方示例 YAML，共 8 个参数项不同：vx_max/vx_min/vy_max/wz_max 调低；Nav2 到达容差由 0.03 m/0.06 rad 改为 0.12 m/0.15 rad，之后我方末段控制再收敛到 0.02 m/0.03 rad。velocity_smoother 的两组速度参数也调低，但我方 launch 未启动该节点。这些是参赛算法配置差异，未修改世界或物理模型。
5. **几何参数有固定假设**。地面透视高度 0.11639364 m、相机水平安装、弹道高度 0.26 m、靶面距离估计以及四个路线坐标来自练习包。官方若调整相机、初始位姿、地图或射击高度，需要重新适配；仅话题名相同不够。
6. **练习中没有正式裁判闭环**。当前发布识别/声明话题，但练习包未提供完整正式裁判反馈。DONE 仅表示流程完成，不能证明每点进入有效、移动靶命中图案正确、环数或官方总分。最终消息发布时裁判是否已订阅也需核实。
7. **图片分配覆盖有限**。官方随机脚本说明每类各选一张、五类随机分配到 0…4。已测默认与部分随机副本，不是所有组合；部分默认/历史运行中类别可重复，不能代表正式随机覆盖率。
